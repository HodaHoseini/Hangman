# Hangman
Hangman Game

A simple command-line version of the classic Hangman game written in Python.

The program randomly chooses a word and the player must guess its letters before running out of lives.

Features
Random word selection
Six available lives
Displays correctly guessed letters
Tracks incorrect guesses
Detects repeated guesses
Win and lose conditions
Technologies
Python
random module
Python Concepts Practiced
Lists
Loops
Conditional statements
String manipulation
Random selection
User input
Importing data from another Python module
Project Files

The main program is:

Hangman.py

The project also requires a words.py file containing the word list used by the game.

How to Run

Place Hangman.py and words.py in the same directory and run:

python Hangman.py

Purpose

This project was created to practice Python fundamentals by developing an interactive word guessing game.
